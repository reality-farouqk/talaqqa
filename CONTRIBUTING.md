# Contributing

## Add or fix a course
1. Fork the repo and add/edit a file in `content/courses/` (copy an existing one).
2. Run `npm run build`. It validates your file and tells you what is wrong.
3. Open a pull request. Say who the teacher is and why the course is worth including.

## Content guidelines
- Credit the teacher or channel and link to the original source.
- Use only videos that allow embedding. Do not add videos from creators who have asked not to be included.
- Prefer clear, well-structured series from recognised teachers. Keep lesson order logical for a beginner.
- Titles and summaries should be accurate and neutral.

## Code
Keep changes small and focused. Open an issue first for large features.
